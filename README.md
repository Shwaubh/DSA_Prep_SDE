# DSA_Prep_SDE

My go-to place to read/write the DSA questions I solve while preparing for SDE 2.

## Structure

- One folder per topic (`trees/`, `arrays/`, `graphs/`, ...)
- One file per approach, named `problem_name_<trick_or_pattern>.py`
- Complexity (when noted) is written as a comment at the top of the file
